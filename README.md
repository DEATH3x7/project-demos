# BGI成果展示

Two browser-based project demonstrations:

- **Evaluation Workbench:** explore illustrative evaluation results, compare agents, customize charts, and export figures and data.
- **Clinical Excel-to-JSON Explorer:** inspect a fully synthetic workbook and output actually generated by the Python extraction tool. Follow source rows, structured records, visit links, and separate evaluation references.

No real patient data, private pipeline source code, credentials, or external model calls are included. The pages explore prepared outputs; they do not execute extraction or evaluation.

Open `index.html` locally or use GitHub Pages configured for `main` and the repository root.
